## 阶段三：Linux 部署

**目标**：在 Linux 上部署整套系统

### 环境准备

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y python3 python3-pip python3-venv git

# 克隆仓库
git clone https://github.com/MYJ-GOD/M-Language-Core.git
cd M-Language-Core

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r python/mcp/requirements.txt
pip install -r python/tool_router/requirements.txt
```

### 配置

```bash
# 创建配置文件
cat > .env << EOF
MCP_SERIAL_PORT=/dev/ttyUSB0
MCP_BAUD=115200
MCP_AUDIT_DIR=data/mcp
MCP_LIR_FILE_ROOT=data/lir_sandbox
EOF
```

### 启动

**开发模式**：
```bash
# 终端 1：MCP 服务器
cd python/mcp && python server.py

# 终端 2：路由器
cd python/tool_router && uvicorn router:app --host 0.0.0.0 --port 8000
```

**生产模式**（systemd）：
```bash
sudo tee /etc/systemd/system/mcp-server.service << EOF
[Unit]
Description=M-Language MCP Server
After=network.target

[Service]
Type=simple
User=$USER
WorkingDirectory=$(pwd)
EnvironmentFile=$(pwd)/.env
ExecStart=$(pwd)/venv/bin/python python/mcp/server.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable mcp-server
sudo systemctl start mcp-server
```

### 验证

```bash
# 检查服务状态
sudo systemctl status mcp-server

# 测试 MCP 服务器
curl http://localhost:9001/mcp

# 运行测试
cd tests && python -m pytest -v
```
